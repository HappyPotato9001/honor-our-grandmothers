# In Plain Sight

**A Memorial to Elderly Asian Women Targeted During COVID-19** — Intersectional Memory, Elder Protection, and Solidarity.

A responsive, senior-accessible single-page digital memorial for **GitHub Pages** (static HTML/CSS/vanilla JS — no build step).

## Live site

After Pages is enabled: `https://happypotato9001.github.io/honor-our-grandmothers/`

## Features

- Font scaler, high-contrast mode, and languages: English, 廣東話, 普通话, Tagalog, Tiếng Việt
- Interactive tribute candle counter
- Five memorial zones (timeline, scapegoating/language barriers, Stop AAPI Hate stats + testimonies, reflection mirror + before/after routine, resistance)
- Pledge wall with localStorage

## Deploy

Push to `main`, then set GitHub Pages source to **Deploy from a branch** → `main` / `/ (root)`.
